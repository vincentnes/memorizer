Local Export

如何產生瀏覽資料

關閉目標瀏覽器後，在這個專案資料夾執行 python tools/export_browser_history.py --browser chrome --days 7。 它會複製本機瀏覽器歷史資料庫，只輸出網址、標題、時間、估計停留秒數和分類。 若要把可讀取的網頁正文也一起帶進來，可執行 python tools/export_browser_history.py --browser edge --days 7 --fetch-content。 如果正文在右邊主欄，使用 python tools/export_browser_history.py --browser firefox --days 7 --fetch-content --content-region right。 若要讓「更新 JSON」按鈕自動執行 Python，請用 python tools/local_server.py 啟動本機 app。

輸出檔：browser_history_export.json
